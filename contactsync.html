「내 연락처 관리」 개인정보처리방침

본 개인정보처리방침은 Google Play에 게시된 다음 앱에 적용됩니다.

  • 앱 이름: 내 연락처 관리 (영문명 ContactSyncApp)
  • 패키지명: com.jtrkor.contactsync
  • 개발자: JackTheRipper

개발자 JackTheRipper(이하 "개발자")가 제공하는 「내 연락처 관리」(이하 "앱")은 사용자의 개인정보를 중요시하며, 「개인정보 보호법」 및 관련 법령을 준수합니다.

1. 수집하는 정보

앱은 아래 정보에 접근합니다:

  • 연락처(이름, 전화번호, 이메일): 기기에 저장된 연락처를 앱 내부 데이터베이스에 동기화하기 위해 읽기 전용으로 접근합니다.

앱은 수집한 정보를 외부 서버로 전송하거나 제3자와 공유하지 않습니다.

2. 정보의 이용 목적

  • 기기 연락처를 앱 내 목록으로 표시 및 검색
  • 연락처 데이터의 로컬 동기화 (하루 1회 및 기기 재부팅 후 백그라운드에서 자동 실행)
  • 사용자가 직접 요청한 경우, 앱 내 연락처 목록을 엑셀(.xlsx) 파일로 내보내기

3. 정보의 저장 및 보관

수집된 연락처 정보는 기기 내부 저장소에만 저장됩니다. 외부 서버, 클라우드 서비스로 전송되지 않습니다. 앱을 삭제하면 앱 내 저장된 모든 데이터가 함께 삭제됩니다.

엑셀 내보내기: 사용자가 "엑셀 내보내기" 버튼을 눌러 저장 위치를 직접 선택한 경우에만 파일이 생성됩니다. 파일은 사용자가 선택한 위치(기기 저장소 또는 사용자가 고른 저장 서비스)에 저장되며, 앱은 이 파일을 외부 서버로 전송하지 않습니다. 내보낸 파일의 보관·공유는 사용자가 관리합니다. 앱에는 외부 파일을 가져오는(import) 기능이 없으며, 앱 내 데이터는 수정·삭제할 수 없습니다.

4. 제3자 제공

앱은 수집한 개인정보를 어떠한 제3자에게도 제공하거나 공유하지 않습니다.

5. 권한 안내

  • READ_CONTACTS: 기기 연락처 읽기. 연락처 동기화에만 사용됩니다.
  • RECEIVE_BOOT_COMPLETED: 기기 재부팅 후 하루 1회 자동 동기화 일정을 다시 등록하기 위해 사용됩니다. 개인정보에 접근하지 않습니다.

앱은 연락처 쓰기(WRITE_CONTACTS) 권한을 요청하지 않으며, 기기 연락처를 수정하거나 삭제하지 않습니다.

6. 아동 개인정보 보호

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 개인정보처리방침 변경

본 방침은 변경될 수 있으며, 변경 시 본 페이지를 통해 공지합니다.
